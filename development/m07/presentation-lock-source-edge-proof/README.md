# Disabled three-space edge correction

11ea preserved all old measurements but stopped at EDGE_ROLLBACK_UNCONFIRMED;
the original native error was masked. Its immutable pure renderer reproduces
three missing spaces in two edge request templates (`::uuidwhere` and twice
`::uuidand`). That is a definite harness syntax defect, not a product security
finding or recovered native diagnostic.

This new default-off wrapper pins every consumed library and never runs an old
controller/claim. It corrects only those exact run-bound templates at the owned
session request boundary, with inverse byte equality. All16 emitted edge query
strings are parser checked. Every probe, baseline assertion,8s bound, SQL role,
candidate function and source-lock/security/equality/race condition stays exact.
The preceding seven seed aliases and three fixture SHA256 expressions remain
composed through their frozen libraries. Fresh private/controller/evidence/
Docker-label/purpose namespaces and a new runtime UUID are still required.

The request wrapper also records the first observed propagated owned-request
error's closed phase and whitelisted SQLSTATE/transport code before rollback
handling can mask it. It reads no diagnostic payload, stores no SQL, message,
stdout/stderr or personal data, and rethrows the identical error. Unknown codes
remain unclassified; a cleanup rejection is not called the primary cause.
The original sessions array and cleanup/rollback methods remain in place.

No new run is authorized by this preparation. Peer and Root review precede any
arming or dispatch. All52332/11ea measurements/failures/claims/source bytes stay
unchanged. Local synthetic acceptance remains separate from canonical/provider
or production performance acceptance; no threshold or constraint is relaxed.
