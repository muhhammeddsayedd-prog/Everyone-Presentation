these source transforms. `source.py` reads only function definitions from the
exact pinned synthetic38 metadata; it does not emit COPY data or private rows.

review/generation functions and the frozen English-ported raw helper.

issue, Reviewed, fingerprint and technical-limit construction. Successful typed
rows are reused only for exact keys inside one STABLE invocation. A shared4MiB
accounting budget counts the physical composite, fully serialized row bytes,

not a process-memory SLA. Over-budget rows execute the original query; absence
and denial are never retained. Explicit local found flags preserve lookup
semantics. Role/slot/category reuse requires complete previously visited rows,
with the original queries as fallback. Composite slot/workspace/role FKs keep
the loop and fingerprint cohorts equal.

error precedence at that edge need not match the preceding implementation.

callers retain their existing guards. The lock1ff8 and English helper stay exact.
